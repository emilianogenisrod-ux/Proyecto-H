Documentación del sistema

Gestor de citas hospitalarias: doctores, pacientes, horarios, citas, pagos y medios. Backend 100 % Python con FastAPI + SQLAlchemy + SQLite. Interfaz web (HTML/CSS/JS) consumiendo la API REST del mismo proceso.

2. Stack tecnológico (Python)

Backend (Python)

  • Python 3.11+ — lenguaje del servidor
  • FastAPI — API HTTP y rutas HTML
  • Uvicorn — servidor ASGI
  • SQLAlchemy 2 — ORM y DDL
  • Pydantic / pydantic-settings — validación y config
  • Jinja2 — plantillas HTML del servidor
  • SQLite — base local (`data/hospital.db`)
  • Starlette SessionMiddleware — sesiones firmadas

Frontend (capa de presentación)

  • Plantillas Jinja2 servidas por FastAPI
  • HTML5 + CSS + JavaScript (fetch a `/api/*`)
  • No hay Node/React/Java en el backend
  • Docs interactivas: /docs (Swagger generado por FastAPI)

Si se requiere otro motor (PostgreSQL/MySQL), solo cambia DATABASE_URL en configuración; el código ORM en Python se mantiene.

4. Cómo funciona el sistema

  1. Arranque: Uvicorn carga app.main:app. En el lifespan se ejecuta init_db() (Base.metadata.create_all), seed demo y entidades de roles.
  2. Login: POST /login valida email/password en catálogo Python, guarda usuario en sesión y redirige al panel según rol.
  3. Panel: cada rol tiene vista propia (/app/admin, /director, /doctor, /patient) que llama a /api/*.
  4. Citas: al crear appointment se valida solape, se inserta fila y se crea payments en estado pending.
  5. Slots: se leen schedule_blocks del doctor y se restan citas activas (servicio Python).
  6. Medios: multipart a disco + metadatos en media_assets; URL pública /media/....

9. Cómo consumir las APIs

Desde el navegador (JS del panel)

const res = await fetch('/api/appointments?status=scheduled', {
  headers: { 'Content-Type': 'application/json' },
  credentials: 'same-origin' // envía cookie de sesión
});
const data = await res.json();

Desde Python (cliente)

import httpx

with httpx.Client(base_url="http://127.0.0.1:8000") as client:
    client.post("/login", data={"email": "emilio@farma", "password": "emilio123"})
    r = client.get("/api/doctors")
    print(r.json())

Crear cita (JSON)

POST /api/appointments
{
  "doctor_id": 1,
  "patient_id": 2,
  "starts_at": "2026-09-10T09:00:00",
  "notes": "Control"
